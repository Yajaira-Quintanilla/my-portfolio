02 · INDIVIDUAL PROJECT

Greenhouse Light Monitor

A light monitoring system that identifies different lighting conditions using an LDR sensor and LEDs.

THE CHALLENGE

A greenhouse needs a simple way to identify whether the light level is low, normal or strong.

THE PROCESS & SOLUTION

I used an Arduino board and an LDR sensor. The program reads the light level, classifies it using conditional ranges and turns on the corresponding LED indicator.

WHAT I LEARNED

I practiced sensor readings, conditional statements, thresholds and the connection between programming and electronic components.
