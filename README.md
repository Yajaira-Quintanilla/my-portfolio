# Yajaira — Personal Portfolio

A responsive English-language portfolio inspired by the supplied pastel editorial reference.

## Files
- `index.html` — page content
- `style.css` — layout, colors and responsive styles
- `script.js` — mobile menu and current year
- `assets/profile.png` — add an appropriate portrait
- `assets/about.jpg` — optional image for the About section

## Before publishing
1. Replace `YOUR_EMAIL@example.com` with an academic/professional email.
2. Replace `YOUR-USERNAME` with your GitHub username.
3. Add your photos to the `assets` folder.
4. Review project descriptions so they accurately describe your own contribution.
5. Add real repository/demo links only when you have them.
6. Credit any third-party images, icons or resources you use.

## Run
Open `index.html` in a browser. No build tools are required.

## Publish on GitHub Pages
Create a public repository, upload all files and the `assets` folder, then open **Settings → Pages**. Select **Deploy from a branch**, choose `main` and `/ (root)`, and save.
